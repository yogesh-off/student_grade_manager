# Problem Statement

## Problem statement
Teachers often write student marks in registers or different spreadsheets. Finding grades, percentages, pass/fail and class ranks by hand takes time and mistakes happen easily. A simple offline program is needed that stores student records and gives correct results quickly.

## Scope
**Included:** add, view, search, update and delete students; enter subject-wise marks (0-100) with checking; automatic grade, percentage and pass/fail; report card; class ranking; class statistics; data saved in a JSON file.

**Not included:** graphical or web interface, login for many users, online storage, attendance or fee tracking.

## Target users
- School and college teachers or tutors
- Python beginners who want to see a complete small project

## High-level features
1. **Student management** - add, view, search, update name, delete
2. **Marks and grading** - checked marks entry, grade, percentage, pass/fail
3. **Reports** - report card, class ranking (ties share a rank), class statistics
4. **Reliability** - input checking, clear error messages, data saved in a file
